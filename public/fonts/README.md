# Vendored webfonts

Both faces are served from this origin. Nothing on the site requests
`fonts.googleapis.com` or `fonts.gstatic.com` at runtime — the Stitch exports did,
and the plan forbids it: a font that has to cross a 2G link is a font that will
not be on screen when the page paints.

## Why the typeface

Atkinson Hyperlegible Next was designed by the Braille Institute for readers with
low vision. Its letterforms are deliberately disambiguated (`I` / `l` / `1`), which
is the reason the design system mandates it at every text level.

## Why the icon font is a subset

The upstream Material Symbols Outlined face carries ~4,000 glyphs (948 KB as TTF,
~4 MB as the variable woff2). CarePoint uses 45. The subset is generated by
`scripts/build_icon_font.py`, which:

1. scans `app/` and `components/` for `<Icon name="..." />` usages,
2. **fails** if any name has no glyph in the source face (an unknown name renders
   as blank space, which is how the Stitch sample's `nights_stay` would have
   shipped as an invisible icon),
3. subsets by codepoint and drops the `GSUB`/`GPOS` tables, and
4. writes `lib/icon-codepoints.ts` so `<Icon>` can address each glyph by codepoint.

Regenerate after adding an icon:

```bash
python scripts/build_icon_font.py
```

The unmodified source face lives at `scripts/vendor/material-symbols-outlined.ttf`
and is not shipped to the browser.
